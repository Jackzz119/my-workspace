# 真实环境实测：设备、登录态、兜底与采集

第四步的真实操作与 UI/UX 拓展的走查共用本文件。要借用户的浏览器、设备或登录态时，准备阶段就读 §1–§2：
先探一次能不能进，进不去马上告诉用户要做什么，其余步骤照常推进。

## 1. 先核实控制的是哪台设备

- 浏览器扩展、远程桌面与 computer use 都可能连着别的机器。先列出工具连着的浏览器或设备，再用两条事实核对：
  能不能打开本机 `localhost` 上的服务；页面看到的出口 IP 与本机终端是否一致。
- 用户指定了设备而对不上时，立即停止在那台设备上的一切操作，告诉用户怎么连上正确的那台；在错的设备上开过的标签页列给用户关。
- 在用户的浏览器里只开新标签页、不动已有的标签，结束时关掉自己开的。

## 2. 借来的登录态

- 只做只读交互：浏览、筛选、翻页、排序、搜索、切主题与语言、打开弹窗或抽屉后取消。
  不点保存、删除、提交、发送、导入导出，不改设置；拿不准的不点。
- 不登出、不切账号、不改口令与两步验证：agent 自己登不回去，登出会让后面的实测全部受阻。
- 登不进或会话过期：不替用户输入口令，把要用户做的事写进日志「续接」与报告的「要你做的」，
  先做不依赖登录的步骤与本地兜底，等用户回来补测。
- 真实账号、生产数据、付费服务上的操作只在用户本次明确授权的范围内。

## 3. 兜底阶梯

按顺序取第一个可行的，报告写明用的是哪一档、数字代表哪个环境：

| 档 | 环境 | 能说明什么 |
| --- | --- | --- |
| 1 | 用户指定设备上的浏览器 + 用户的登录态 | 部署环境的真实数据、网络与网关 |
| 2 | 宿主自带的浏览器窗格（窗格可见时） | 目视与单点复验；窗格隐藏时页面按后台运行，预取、LCP 与计时类数字不可信 |
| 3 | 本地同一提交的生产构建 + 隔离的临时库（独立端口与库名）+ 模拟上游 + 独立无头浏览器（全新配置）+ 项目夹具里的测试账号 | 前端与本机服务端本身；可重复、几乎不占主线程上下文，不代表部署环境 |

- 第 3 档的测试账号只用项目种子或夹具里的值，只在本地开发主机上用；带一次性验证码（如 TOTP）的，
  脚本先等进入新的时间窗再取码，同一个码连用会被拒。
- 收尾删掉临时库、停掉预览服务、去掉为实测临时加的启动配置，记进日志；要复现时按项目蓝图重建。
- 走查、截图与快照脚本存进 `AUDIT_DIR/scripts/`（口令只从环境变量读），不只留在会话临时目录。

## 4. 走查矩阵与脚本化交互

- 矩阵：屏或场景 × 主题 × 语言 × 目标宽度（至少宽屏、窄桌面、平板各一档），每格截图并采运行时快照。
  交互按真实用户的任务列（筛选、翻页、排序、弹窗、抽屉、侧板、搜索、键盘与焦点），不只打开页面；空态、错误、加载、长内容各拍到。
- 全局状态（语言、主题、时区）用可靠的方式切（cookie、存储、URL 参数），量测前核对页面真的切过去了：
  点菜单没点中时，整批「英文」量测其实是中文。
- 脚本定位优先用可见文字或稳定的测试 id；跑完逐步核对是否真点中，超时先查脚本、不记成页面问题，没点到的交互列进补测清单。

## 5. Web 页面每屏采什么

- **网络**：全部请求的状态码、重复、瀑布、体积、缓存头、失败与重试；轮询（页面隐藏时还打不打）；
  框架自动预取 / 预加载的数量与范围；控制台错误。
- **运行时**：导航计时、LCP、CLS（带位移来源，先归因再改）、INP 或最慢一次交互、长任务、JS 堆与 DOM 规模、
  各宽度 × 各语言的横向溢出。
- 参照线用当轮核验过的官方阈值（如 Core Web Vitals）并注明来源；项目没有预算时只作参照，不当合格线。
- 改后在同一构建模式、同一数据、同一矩阵格里复测，前后数字并排；截图辅助说明，不替代 profile 与网络记录。
- 在页面上下文里执行的快照脚本（用 PerformanceObserver 收上面几项）存进 `scripts/`，部署环境补测时直接复用。

## 6. 发现怎么分流

- 位移、溢出、对比度、错位这类小缺陷：用户授权了小修的，在发现的那一步修并复测，记进该步报告；没授权的记成发现。
- 授权了修复、但改动牵涉框架、构建或数据获取约定（加载边界、打包配置、请求缓存约定）的，仍先出方案进报告，除非授权明说包括它们。
- 结构、命名、视觉方向类的建议：启用了 UI/UX 拓展的交给拓展（审图、比稿）；没启用的记成发现与建议。
- 本地兜底测不到的（真实上游、网关、真实数据规模）列成部署环境补测清单，写进报告与「续接」。
