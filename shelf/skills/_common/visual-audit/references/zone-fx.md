# 专区：特效与粒子（fx）

点名 `fx`，或完整一轮开审前读。看的是命中、完成、庆祝这些时刻的视觉效果：强度、节奏、读不读得出。七步的细则在 round.md，逐帧取证与试玩规程在 playtest.md，这里只写本专区自己的。

## 1. 审什么

- 命中 / 完成 / 庆祝的强度分级与节奏、粒子的错峰与速度分布、闪光与混合模式在不同底色上是否读得出、层级（特效该在谁前面）、与美术风格是否一致、低动效降级。
- 和别的专区的界线：界面元素的进退场、按压与转场归 `motion`；特效拖慢了画面归 `perf`；材质与整体调性归 `style`。

## 2. 规则库取哪几节

只跑本专区时按下面取；完整一轮照 rules.md 用法第 1 条挑，下面只当本专区的重点提示。

`rules.md` 的 G-01–G-03、E-04、T-13、T-14、M-05、L-13、L-15；K 扫一遍；经验做法看 X-01、X-06。强度、节奏、粒子数这类目标值照 playtest.md §2 当场查，写清来源与适用前提。

## 3. 各步里做什么

- **点名本专区就走试玩这条线**，只走维度 V：一个循环是调研 → 特效视觉 → 双代理验收（playtest.md §1、§4、§9）。完整一轮里走了这条线的，本专区就是它的维度 V；没走的，按本轮挑中的规则看截图；要动起来才量得到的条目写「未测」，不另加胶片。
- **准备**：交互点清单里 `dimension` 含 V 的行是本专区的分母；试玩适配照 playtest.md §3。
- **采证**：单跑本专区时不拍整套截图矩阵，只拍报告要用的现状图；带特效的交互点各出一张逐帧胶片（playtest.md §5），不同底色、连续触发、中途打断、低动效各看一遍。
- **调研**：标了每轮的两条照做（research.md §1）；目标值照 playtest.md §2 当场查，brief 用 `prompts/research.md`。
- **读实现**：粒子与特效节点、着色器与滤镜、混合模式、渲染层级与渲染开关。
- **比稿**：方案先在开发构建里做成真实变体，同条件逐帧拍了再比（playtest.md §7）；要出概念图时按 pitch.md §2「概念、材质、光与渲染、角色与场景」那一行派。

## 4. 验收口径

在 round.md §6 之上加看；完整一轮按本轮范围取，不强制逐条（双代理盲测那条除外，照 playtest.md §9）。

- 同条件重拍胶片前后对照：峰值没有被遮挡或裁切，终态没有残留或闪烁，没有死帧与跳帧。
- 各底色上都读得出；低动效模式下有降级且信息不丢。
- 覆盖率 = V 行里已查的 / 全部适用的。
- 双代理盲测：两位都认为（就本专区而言）可以上架，且本专区没有未处理的高优先级发现（playtest.md §9；条件不省，只对本专区下判断）。
