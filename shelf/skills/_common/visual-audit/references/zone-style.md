# 专区：整体风格与概念（style）

点名 `style`，或完整一轮开审前读。看的是质感、气质与概念立不立得住：界面、画面和品牌是不是一家，高不高级。七步的细则在 round.md，这里只写本专区自己的。

## 1. 审什么

- 整体风格、材质、角色与场景（设计判断与视觉完成件的审核归主美技能，本专区负责取证与判定）。
- 深度、阴影与材质：浮层的层级与光源、面板的质感、半透明面板的可读性、明暗外观下是否都成立。
- 情感与气质：第一眼的感受和产品意图对不对得上、装饰与强调有没有克制。
- 概念与同源：界面和作品画面是否取自同一套色温、材质与光向；把元素截到白底上，若能原样放进任何产品就是没绑定（规则库 X-05）。
- 典型反馈是「不够 X 的级别」「没有质感」「不高级」「单调」：**先照 round.md §0 第 2 项翻成可检查的属性并请用户确认**，再进后面的步骤。
- 和别的专区的界线：信息怎么排、找不找得到归 `ui`；粒子与光效的强度归 `fx`；动的过程归 `motion`。

## 2. 规则库取哪几节

只跑本专区时按下面取；完整一轮照 rules.md 用法第 1 条挑，下面只当本专区的重点提示。

`rules.md` 的 M；情感 / 陪伴 / cozy 类产品加 E；画面上叠界面的产品加 G（以 G-04、G-06–G-09 为主）；P-05、P-06、P-15–P-18；V-04–V-06；K 扫一遍；经验做法看 X-02–X-07。

## 3. 各步里做什么

- **准备**：稳定项与会换项（场景与背景、镜头、主体、色调、内容量）在本专区最要紧，会换的只能当风格参考（round.md §0 第 4 项）；设计系统的铁律与冻结项先列出来。
- **不走试玩这条线**：本专区没有对应的维度，产品是游戏也只走七步；独立复审照 round.md §6。
- **采证**：同一场景表用 `--set` 按第 0 步定的外观 / 主题 / 时段拍，基准外观之外的至少各拍一张；数值以材质（圆角、投影、模糊）与「文字压在真实背景上的对比度」为主；比稿用的干净底图在这一步拍好（round.md §1）。
- **调研**：标了每轮的两条照做（research.md §1），加「领域心理与质感」「材质与组件专项」。
- **比稿**：按 pitch.md §2「概念、材质、光与渲染、角色与场景」那一行派；出稿人交一张换了底图或外观的验证图，评审必答「换了还成立吗」（pitch.md §3 第 5 节、§6 第 5 条）。
- **实施**：材质在定下来的版式上做（先版式后材质，round.md §5）；要新美术素材的先占位、登记要图。

## 4. 验收口径

在 round.md §6 之上加看；完整一轮按本轮范围取，不强制逐条。

- 第 0 步翻好的属性逐条对照改前改后，属性是用户确认过的那一版。
- 第 0 步定的每种外观、换一张背景 / 换一个机位各看一次，仍然成立。
- 材质数值、对比度最差点逐项对照；铁律与冻结项没有被改动，动了的有决定编号。
