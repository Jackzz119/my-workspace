# 可批注报告页 · 参考（按需读）

只在下面两种时候读：用户问页面上某个功能怎么用；要改 `annotate.js` 或排查批注层的问题。写报告、发布、处理批注都不需要它。

## 页面上怎么用（完整说明）

- 选中文字点「批注这段」；或点「批注」进入批注模式，再点段落、卡片、图、表格行；或点「留言」写一条不针对位置的意见。写批注的窗口和留言一样固定在右下角（手机上从顶部垂下），不挡在批注的内容上，被盖住的内容滚一下就看得到。回车存下，Shift+回车换行。输入框随内容增高，到窗口上限后在框内滚动，「存下来」按钮一直看得到。要附图就在写批注时粘贴截图、把图拖进来，或点「图片」选（claude.ai 上）。
- 批注过的文字高亮，批注过的元素加虚线框和编号；点高亮或编号打开那一条。刷新后标记还在。
- 「清单」列出全部批注，默认按写的先后：点引文跳回原处并闪一下；每条可「改」「删」（删要再点一次确认），可以用 ↑ ↓ 调顺序（键盘可用），桌面上也可以按住左侧把手拖动；清单编号、页面上的编号和复制出的清单都跟着新顺序，顺序存在报告里；「复制全部」得到下面的清单，复制成功后清单自动收起；点清单外面也会收起（拖着选文字不算）。有批注时，右下角「清单」旁边也有一个「复制全部」（窄屏上写「复制」），不打开清单就能复制；浏览器不让写剪贴板时，它打开清单并把全文选中，手动复制即可。
- 页面里的图（报告插图、批注附图）点一下全屏看：滚轮、双指捏合、底下的 − / + 按钮或 + − 键围着指针放大，最多 32 倍，2 倍起像素画成清楚的方块，能看到单个像素；拖着平移，「适应」或 0 键回到整张，「1:1」或 1 键看原尺寸，点图在整张和原尺寸之间切换；点旁边、点 ✕ 或按 Esc 关掉；批注模式下点图仍是批注它。
- 搜索：按 Ctrl+F（Mac 上 ⌘F，焦点要在页面里），或点右下角的放大镜，顶上出现搜索条（应用自带的查找不一定搜得到 artifact 框里的内容，手机上也没有查找，所以页面自带一个）。输入即搜，不分大小写，中文照搜；命中全部标蓝，当前这处是实心的，显示「第 i / 共 n 处」；回车 / Shift+回车、↑ ↓ 或 ⌘G / Ctrl+G 跳下一处 / 上一处，折叠区块里的命中自动展开。Esc 或 ✕ 关掉，标记全清，下次打开上次的词还在。在搜索条里再按一次 Ctrl+F / ⌘F，就是浏览器或应用自带的查找。
- 左侧目录（桌面宽度）点标题旁的按钮收起，只留按钮，正文移到页面中间；再点展开。各人记在自己的浏览器里。
- 细节默认收起，点标题行展开；标题下和左侧目录顶上有「全部展开 / 全部收起」，打印时全部展开。收起的块里有批注时，编号挂在块的标题行上，点编号打开那一条。
- 批注存在这份报告里（claude.ai 上）：换设备、隔几天、浏览器缓存被清都还在，写到一半去做别的事回来接着写；写完可以「复制全部」贴回对话，也可以直接说「批注好了」。不在 claude.ai 上的页面只存在这台设备的浏览器里，存不住时页面会提示刷新前先复制。

## 批注层的实现

- `annotate.js`：批注层本体，无依赖、自动启动，由 `inline.mjs` 去掉整行注释与缩进后内联进页面。按钮、面板、提示、看图层、搜索条用同一条弹簧曲线（约 2% 回弹、0.54 s 稳住）入场、悬停与按压，离场 0.16 s 直接淡出不回弹，同一面板原地重画不重播入场；系统开了「减少动态效果」时全部不动。在 claude.ai 上（页面声明了 `db` 能力）每条批注是这份 artifact 数据库 `annotations` 集合里的一个文档；浏览器存储只作缓存，在别的托管上是唯一的存处。清单的顺序是每个文档的 `pos`（与 `at` 同一刻度的毫秒数；没有 `pos` 的旧批注按 `at`），调顺序只用 `update` 写位置变了的文档的 `pos`（通常就是被移动的那一条），写失败就换回原位并提示。页面还声明了 `assets` 时，批注可以附图（粘贴、拖进来或点「图片」选），图存进这份 artifact 的资源库，文档的 `imgs` 记它们的资源 id；大图先缩到长边 2000px 的 JPEG。页内搜索的命中用 CSS 高亮标出，不改页面的 DOM，批注的锚点和标记不受影响。批注落在收起的折叠块里时，编号挂在块的标题行上；从清单跳过去、搜到块里的字，都先展开再定位。
