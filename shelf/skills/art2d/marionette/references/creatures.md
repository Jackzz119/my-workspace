# 动物角色：趴着、卧着的那一类

> 按需加载。角色不是坐在桌后的人、而是趴 / 卧着的动物时读。第二个生产案例：陪读的猫（白底灰斑长毛，趴成「面包」，
> 在桌上台灯旁）。流水线和运行时照常，下面只写和人不一样的地方；这些部位、眼睛与受光还在项目里的猫适配层里，
> 运行时模板没收，参考实现的位置登记在项目文档里。

## 和坐着的人不一样的几处

| | 坐在桌后的人 | 趴着的动物 |
| --- | --- | --- |
| 截断线 | 躯干被桌面截断，`cut_y` | 没有：整只在桌面上，贴桌那条线是接触线 |
| 呼吸权重 | 截断线处 0、肩以上 1 | 贴桌处 0、背最高处 1，头只跟 0.2，搭在桌上的尾巴为 0；自己写遮罩放进 `breath.masks`——默认算法会把整只一起抬起来，和整体缩放没区别 |
| 微摆 | 上半身绕截断线轻摆 | 身体不摆：`leanRad: 0`；只有头和尾巴轻摆（铁律 8） |
| 动作从哪来 | 姿势图 + 手势（一缩、笑颤） | 姿势图 + 部位绕根转（耳朵、尾巴、头） |
| 眼睛 | 睁 / 闭两张 | 四张：默认的软半眯、半眯、闭、看你；半眨、眨眼、慢眨都是它们的序列 |
| 出场 | 淡入淡出 | 同一场景的人怎么出场它就怎么出场 |
| 受光 | 房间的 tint | 房间的 tint；挨着灯时再加方向光与轮廓光（`runtime.md`「受光」） |
| 影子 | 不要（被桌面截断） | 贴桌的窄深接触影 + 背光一侧的软投影，跟着灯 |

## 部位：耳朵、尾巴、头

每个部位一个多边形 + 根 + 尖，算成顶点权重：多边形边缘按一格半羽化，从根到尖由 0 长到 1（`ramp` 是长满的位置占根到尖的比例）。
动作是随时间变化的转角（绕根）、位移和压缩，叠在呼吸和形变之后。同一轮廓的姿势（只改了嘴和眼的哈欠帧）共用 anchor 的部位，
形变进行中也照常动，这样一条链两头的头抬得一样高。

| 部位 | 根在哪 | ramp | 做什么（第二个案例的数） |
| --- | --- | --- | --- |
| 耳朵 | 耳根 | 1（只有耳尖转满） | 抖一下：100ms 外转 15°、停 50ms、280ms 回，偶尔连抖；哈欠时向后 9°，打盹时向外 4° |
| 尾巴 | 尾巴中段 | 1 | 尾尖敲两下（抬 0.5s、落 0.75s，弯约 12°）；被摸时尾尖慢摆 ±4° |
| 头 | **脖子：下巴后面**，不是胸口 | 约 0.1（到下巴就满） | 蹭手：往手那边歪 3.5° 推 3px，叠 ±0.8° 的慢蹭；哈欠抬 9px、略歪、略缩；打盹低 8px、竖向压 4.5%（像往前低头），不歪 |

根放在胸口、ramp 0.3 的头（第一版）转起来会带着上半身一起摆，就是不倒翁。

## 眼睛：四张，一张网格

半眯、闭、看你都从 anchor 用眼睛遮罩编辑出来，`align_to: anchor` + `free: eyes` 对齐（闭眼走 `blink`）。默认那张是软半眯（约 70% 开）、
眼神落在桌面上，不盯镜头。节奏（调研）：清醒的猫全眨每分钟只有 0.2–0.5 次，主要靠半眨（6–15s 一次）；慢眨 =
看你 1.5s → 两次半眨 → 闭 1.6s → 半眯 0.75s 慢睁，用在看你之后、被摸收尾、你回来时。

要眼睛整体大一点：不生成，四张用同一个局部放大镜变换（`generation.md`「模型做不到的三件事」）。

## 哈欠：头不动、嘴张开的链

- 出图：只开嘴、下颌、胡须垫和眼睛的遮罩，先出张大的，再从它出「张开约三分之一」的中间帧；两张都 `align_to: anchor`，`free` 写眼带和嘴框，`chain: true`。
- 链：`anchor → 半张 → 张大`，`back: true`，`swap: "wide"`；眼睛先用眼睛图闭上（约 0.2s），链只管嘴；张大停约 1.1s，倒着收回，
  回到 anchor 时眼睛还闭着，再慢慢睁开（要睡了就不睁）。
- 头在整条链上抬几像素（网格），耳朵向后；吸一口气（呼吸权重整体再抬一点）。
- 只在换状态时打（要睡了、刚醒），不按时间随机。

## 打盹

没有打盹图也行：闭眼图 + 头往下低一点并竖向压缩（看起来像往前低头），耳朵向外放松，呼吸慢约 12%。头不歪——
第一版打盹图让头歪了约 10°，看着像在犯晕。

## 影子

两层，正片叠底，暖深棕：贴桌的窄深接触影一直在（灯越亮越深，0.6–1），背向光源的软投影只在灯亮时有，随灯一起淡掉。
都画在桌面上、角色下面，随呼吸轻微变宽。
