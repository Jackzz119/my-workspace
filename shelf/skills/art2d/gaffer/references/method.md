# 方法：光比、切图、配置、自测

## 光比怎么算

对每个状态 s（参考状态 ref 的光比恒为 1）：

1. 两张底图转线性光：`L = srgb_to_linear(图 / 255)`
2. 逐像素逐通道取对数比：`log r = log((L_s + ε) / (L_ref + ε))`，ε ≈ 0.002
3. 权重 `w = 受光面 × clamp(亮度(L_ref) / 0.02, 0, 1)`：排除区为 0，参考图里几乎全黑的像素也不算（比值是噪声）
4. 归一化卷积：`近 = G_σ(log r · w) / G_σ(w)`，σ ≈ 24 px（1536 宽）
5. 排除区深处 `G_σ(w)` 接近 0：再用宽 5 倍的 σ 算一遍 `远`，按 `置信 = clamp(G_σ(w) / 0.3, 0, 1)` 混合
6. `光比 = exp(置信 · 近 + (1 − 置信) · 远)`，截到 [0.02, 4]

为什么是对数空间：比值是乘法量，对数里平均才不偏向亮的像素；对数平均也让「一块很亮的颜料」不会把周围的光比拉高。

为什么颜料能约掉：漫反射面 `像素 = 反照率 × 照度`，同一处的反照率在两张图里一样，相除只剩照度之比。
不成立的地方：**镜面反光**（桌面上的窗景倒影）、**自发光**（灯罩、窗外）、**两张图画法不同**（出图工具每张重画，
笔触和小物件会漂）。前两种用排除区；第三种靠 σ 平滑掉，剩下的在自测里看得到。

**逆光的轮廓**（太阳从物件背后照过来，边上一道亮边）不在低频光比里，重打光补不出来。
这时自测的误差只比不打光略小；要么接受，要么在那几个状态给物件加一道运行时的轮廓光（marionette 的轮廓光做法）。

## 受光面与排除区

- 排除：窗玻璃（窗外景色）、灯罩和灯泡、屏幕、蜡烛火焰——一切自己发光或透明的
- 保留：墙、地、桌面、家具、布料
- 桌面这类亮面会把窗景倒影算进来，物件放在桌上时 σ 取大一点

配置里用矩形 `[x, y, w, h]` 或多边形 `[[x, y], ...]` 列出排除区，也可以给一张遮罩图（白 = 受光面）。

## 切图（`alpha` 三种，另有加细的局部）

| 模式 | 透明度从哪来 | 用在 |
|---|---|---|
| `diff`（默认） | 物件图和它画在上面的那张图逐像素比差：`d = max_通道 |src − base|`，`α = smoothstep(lo, hi, d)`；先闭运算补洞、开运算去散点，再并上 `solid`（肯定是物件的区域），乘上 `region` | 椅子、书、猫：形状复杂的物件 |
| `patch` | 只用 `region` 多边形，边缘羽化 | 整条替换的区域（窗下那一条换成长座）：里面的墙一起换 |
| `cut` | 参考底图和它的「拿走版」（`behind`）比差；每个状态直接用那张底图里的像素，不重打光 | 底图里本来就画着、要变成独立图层的东西（原来的椅子） |
| `scale` 局部 | `region` 多边形；源图是底图矩形 `at` 的 `scale` 倍大图 | 镜头会凑近的一角重出一张更细的图（2 倍屏上真有细节）；光比放大到它的尺寸再乘，框仍按底图 px |

- `threshold: [lo, hi]`：lo 要高于出图工具的整体漂移（常见色差 4–7，取 10–16），hi 取 30–45
- **去背景色**：半透明边上 `C = αF + (1−α)B`，已知背景 B，`F = (C − (1−α)B) / α`（α < 0.05 时不除）；玻璃前用 blur-fusion，见 `edges.md`
- **影子**：物件投在背景上的影子也是差值，会以半透明的深色留下来——这正是要的接触阴影。不想要就在 `region` 里不圈它
- `emissive`：发光区（多边形 / 矩形），重打光时保留参考色，边缘羽化 3 px
- `glass` / `glass_edge` / `glass_reach` / `glass_soft`：物件身后会变的透明区（窗玻璃、屏幕）里怎么定边、怎么去掉画上去的窗光，
  见 `edges.md`「玻璃前」。玻璃里只信实心区，实心区要盖住物件在玻璃前的全部
- 加细的局部：`scale`（整数倍）、`at: [x, y, w, h]`（它盖住的底图矩形）、`source`（`w·scale × h·scale` 的图）、`region`、`emissive`（都按底图 px）。
  源图怎么来：从参考状态的合成图（底图 + 它下面的布景）裁出 `at`，让出图工具重画细节；工具会改明暗，用低频光比拉回原画
  （`F_细 × blur(原图放大) / blur(F_细)`，σ 约十几 px），只留它的细节

## 配置

```json
{
  "root": "相对配置文件的项目根",
  "reference": "参考状态名",
  "states": { "<状态名>": { "plate": "底图", "behind": "同一张图拿走某物的版本（可选，cut 用）" } },
  "light": { "sigma": 24, "wide": 120, "exclude": [[x, y, w, h], [[x, y], ...]], "mask": "可选遮罩" },
  "out": "输出目录",
  "name": "set-{piece}-{state}.webp",
  "quality": 88,
  "away_behind": true,
  "review_crop": [x, y, w, h],
  "pieces": [
    { "id": "名字", "alpha": "diff|patch|cut", "source": "物件图", "base": "它画在上面的图",
      "region": [...], "solid": [...], "emissive": [...], "threshold": [12, 36],
      "close": 2, "open": 1, "feather": 1.5, "glass": [...], "glass_edge": "read|trace", "glass_reach": 4,
      "glass_soft": 0.8, "when": "always|here|away" },
    { "id": "加细的一角", "scale": 2, "at": [x, y, w, h], "source": "2 倍图", "region": [...], "emissive": [...] }
  ],
  "actors": [ { "id": "名字", "spot": [x, y, w, h] } ]
}
```

- 状态名就是输出文件名里的 `{state}`，通常和底图文件名对得上，运行时按名字找
- 一件物件改了内容（重切、重出图）就给它换文件名：件里写 `"name": "set-seat-2-{state}.webp"`（活物写 `file`）。
  图片常被 CDN 和浏览器缓存几个小时，同名换内容时，旧图和新代码（比如挪了位置的光晕）会对不上
- `pieces` 的顺序就是叠放顺序（后面的在上）；`when` 只影响 `preview` 怎么叠：`here` 有人时、`away` 空着时
  （`away` 的预览用 `behind` 当底，`away_behind: false` 关掉）
- 输出：每件每状态一张，裁到透明度的外框；终端打印每件的框 `{x, y, w, h}`，抄进运行时的场景模板

## 自测

- `check --piece <id>`：只对 `alpha: "cut"` 的物件。从参考图取它，乘光比，和每个状态里真实画的样子比，
  打印「重打光误差 / 不打光误差」和三通道偏差（sRGB 色阶）。重打光误差应在个位数，并明显小于不打光
- `--review <目录>`：`here.jpg` / `away.jpg` 每个状态一格，`<here|away>-<状态>.jpg` 单张；看接缝、颜色、影子、发光
- `tint`：每个活物每个状态一个十六进制 tint（线性光比开 2.2 次方根换成 sRGB 乘数）；光比超过 1 的会提示
