# 运行时：图层、淡化、光源、活物

和引擎无关的做法；数值是 1536×1024 的厚涂室内场景、30–60 fps 的参考值，项目以自己的登记为准。

## 图层顺序（远到近）

```
底图（该状态）
  被拿走的东西后面（补丁，「空着」时淡入）
  常驻布景（窗边座……）
  光源光晕（加法混合）           ← 只照到它后面和旁边的东西
  会换样子的布景（原来的椅子 / 转过去的椅子 / 倒扣的书）
  贴在布景上的活物（窗边的猫）
人物、桌上的活物……
```

光晕要放在「光源本身」和「挡在光源前面的东西」之间：灯笼在椅子后面，光晕就在椅子下面，不然椅子正面会被照亮。

## 每个状态一组，跟着底图走

- 布景每个状态各一份，挂在那个状态的底图组里：底图组交叉淡化（换时辰 900 ms、开关灯 400 ms 级）时布景一起淡，
  永远不会出现「底图换了光、布景还是上一种光」的一拍
- 关灯版叠在开灯版上，透明度 = 灯暗了多少，和底图的做法一样
- 「有人 / 空着」两套布景各在一个容器里，容器透明度交叉淡化（约 420 ms，和人物淡入淡出同步）

## 整层淡化

一个容器里叠着几层（开灯版底下压着关灯版、补丁盖在底图上），淡入淡出时要**整层**淡：多数引擎的容器透明度是分别乘进每个子层的，
透明度 a 时下层会以 a(1−a) 的分量透出来，中途最多透 25%。症状：关着灯换时辰，灯在过渡中途亮一下再灭；
椅子先变成开灯的样子、最后一刻跳回关灯的样子。

做法：容器透明度停在 0 / 1 之间时，把它先画进一张离屏图，再按透明度盖上去（PixiJS 用 `AlphaFilter` 代替容器的 `alpha`，
Unity 的 CanvasGroup / 离屏 RT、CSS 的 `opacity` 都是整层的）。只在淡的那一会儿多一遍离屏，停在 0 或 1 时撤掉。
验收：关灯切时辰、开灯切时辰，逐帧录，灯罩和物件的亮度单调变化、不冲过两端。

**轮流占同一个位置的透明物件要混，不要叠。** 底图不透明，新的一张盖在旧的上面淡入、盖满再撤旧的就对；
抠出来的物件（每个时辰一份的椅子）有软边，旧的那份留在底下时，软边处两份叠成更不透明的一圈，撤掉旧的那一帧边缘一跳，
看着像「离屏图消失时闪了一下」。做法：它们的父层在交叉期间也画进离屏图，旧的从当前透明度淡到 0、新的淡到 1（两者之和始终为 1），
每份按透明度**加法**混进这张离屏图（预乘颜色下 `ONE, ONE`），父层再整张盖到场景上一次：结果正好是两张图按比例的混合，
软边不会叠厚，背景也不会在中途透出来（直接两份各淡一半时中途会透 25%）。PixiJS：每份的 `AlphaFilter` 的 `blendMode` 设 `'add'`，
父层挂一个透明度 1 的 `AlphaFilter`。验收：逐帧截图，相邻两帧之差在淡完那一帧不该突然变大、也不该集中在物件轮廓上。

## 一个时钟

依赖同一种光的东西都跟着底图淡的那个进度走：活物的 tint、贴在布景上的活物的增益、光源强度。
换时辰时活物的光不要一下设到新值（猫在第一帧就变暗，底图还要 900 ms 才换完），从当前值插到新值，时长和底图的淡化一样。

## 光源：光晕 + 闪烁

光晕：一张预先画好的径向渐变（中心不透明的暖色 → 边缘全透明，衰减用 `(1 − d²)²` 一类的平滑曲线），加法混合，
半径约等于光能照到的范围（小灯笼 90–130 px），中心再叠一个小而亮的核（15–25 px）。

强度：`各时辰强度 × (1 + 闪烁)`。日落时环境很亮，小灯几乎看不出（0.2–0.3）；暮色 0.4–0.6；夜里 0.6–0.8。
关不关台灯不影响小灯笼本身，但关灯后周围暗了，同样的光晕看起来更显眼——这是对的，不用补偿。

闪烁（烛火）：

```
n(t) = 0.55·sin(2π·t/1.7) + 0.3·sin(2π·t/0.83 + 1.3) + 0.15·sin(2π·t/0.37 + 2.1)   // 三条不成整数倍
dip  = 偶尔（每 4–9 秒一次）0.12 深、0.25 秒的小暗跳，平滑进出
闪烁 = 幅度 × n(t) − dip，幅度 0.05–0.1；光晕的核用 1.5 倍幅度
```

- 低动效：不闪，强度固定
- 只有光晕在动，画里的灯笼本体不动（它的亮已经画进布景）

## 活物的场景光

- 基础 tint：在活物待的位置量出的每个状态的值（`light.py tint`），开灯 / 关灯两个之间按灯的亮度线性插值
- **单独画、颜色很浅的活物**（白猫、白衬衫）：量出的增益带着底图很重的画面色（蓝调的夜、橙色的灯），乘在深色木头上看着对，
  白毛会被染透——夜里发黄、关灯发蓝、黄昏像在发光。先收一收再乘：色度压到一半（每个通道 = 亮度 ×（1 +（通道 / 亮度 − 1）× 0.5））、
  亮度超过 1 的部分按 0.4 收，再乘一个 RGB 曝光（这张画自带的光和参考底图的光之比：画的时候挨着暖灯就偏暖、偏亮）。
  三个数放在一个函数里，所有状态一起调；每张底图都叠上去看一遍（一只白底灰斑、挨着台灯画的猫：曝光 0.82 / 0.77 / 0.705，六种光里都坐得住）
- 挨着光源：tint 再往光源色混，`混合 = 光源强度 × 靠近程度 × 0.2–0.35`，跟着闪烁一起轻微变（幅度减半）
- 方向光、轮廓光、影子（活物紧挨灯、要有立体感时）：见 marionette `references/runtime.md`「受光」
- **活物挡掉的光**：猫坐在被窗照亮的毯子上，它身前那一块该在它的影子里（不然毯子顶上一道蓝光从猫身下透出来）。
  `light.py shade` 按状态量出乘子，运行时一层 `multiply`、乘子随底图的时钟插值，放在活物图层**下面、外面**
  （活物图层有滤镜时，滤镜那张图的起点是透明的，multiply 在里面不起作用），跟着活物淡入淡出、换姿势时让位

## 性能

- 布景贴图裁到外框；每个状态一份，只有当前显示的那组在画（透明度为 0 的组关掉可见性）
- 光晕一两个精灵，不用滤镜；闪烁只改透明度
- 布景跟着底图用同一套视差网格（按它站的位置取景深），镜头动时不会和底图错开；自己站在别的东西前面的布景
  （转向窗的椅子）整件按它站的那一点的深度滑，不用身后画的深度，否则会跟着身后的深度弯
- 整层淡化的离屏只在淡的那一会儿有；加细的局部（2 倍图）每个状态一份，显存按 宽×高×4×状态数 估
