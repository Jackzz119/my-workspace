# 上架平台速查（2025-2026 数据）

## 分成与规模对比

| 平台 | 分成（开发者拿） | 规模/定位 |
|---|---|---|
| Steam | 70%（$10M 后 75%，$50M 后 80%）| ~1.2 亿 MAU，PC 绝对主场；实践中多平台开发者 80-95% 收入来自 Steam |
| itch.io | 默认 90%（可自定 0-100%）| 80 万+项目；实验/jam/早期验证与核心独立玩家社区 |
| Epic | 88%（2025/6 起每产品每年首 $1M 拿 100%）| ~6800 万 MAU，发现性弱，适合已有流量的作品搏独占/补贴 |
| GOG | 70% | 无 DRM 人群，单机叙事向加分 |
| App Store / Google Play | 70%（小开发者计划 85%，首年订阅后 85%）| 量最大但买量成本高；休闲/超休闲主场，自然量几乎为零 |
| 微信/抖音小游戏 | 视类目 50-70% | 国内免下载场景，社交裂变玩法优先；需版号合规评估 |
| Web（自托管/Poki/CrazyGames）| 广告分成或自营 | Demo 传播与原型验证最快路径，本 Demo 库即此模式 |

## 选择决策树
1. **验证期**：Web/itch —— 零门槛拿真实玩家反馈（本库流程：网页 demo → itch 页 → 攒反馈）
2. **PC 商业化**：Steam 为主战场，itch 同步作社区版；Epic 等谈判筹码
3. **手游**：先问买量模型成不成立（LTV>CPI），成立才值得进商店；不成立考虑小游戏平台借社交裂变
4. **多平台梯次**：itch demo → Steam demo+页 → Next Fest → Steam 1.0 → 主机移植（外包）→ 手机版

## 各平台隐形成本
- Steam：$100/款上架费；胶囊图/预告片/成就等商店素材 1-2 周工作量
- 移动商店：审核合规（隐私/年龄分级）、包体优化、大量机型适配
- 国内：版号周期与不确定性——出海优先是多数独立团队的现实选择
- 主机：devkit 申请+平台认证（TRC/XR）数月，一般交给移植外包
